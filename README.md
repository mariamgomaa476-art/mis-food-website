# MIS Food Website 🍕

This is a web-based food ordering platform developed as part of a Business Information Systems (BIS) project at Helwan University. The project demonstrates front-end development skills and interactive web functionality.

## 🚀 Features
- **Interactive Menu:** View various food items with descriptions and prices.
- **User Authentication:** Simple login and sign-up functionality for a personalized user experience.
- **Order Management:** Ability to add items to an order with quantity selection.
- **Responsive Design:** Built to work smoothly on different devices using CSS and JavaScript.

## 🛠 Technologies Used
- **HTML5:** Structuring the website content.
- **CSS3:** Styling the interface with a modern, responsive design.
- **JavaScript:** Implementing interactive features like authentication, menu navigation, and order simulation.
